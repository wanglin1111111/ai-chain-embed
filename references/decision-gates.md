# 决策闸门：值不值得做、做到哪一级

> 本文件回答三个决策：**要不要去**（一场会/一次学习）、**现在在哪一级**（工具/流程/链路）、**头部数字怎么用**（方向锚 vs KPI）。

## 一、"要不要去"三条件判定

以"要不要去一场会/上一门课/参加一次活动"为通用模型，**三个条件同时满足**才值得投入时间：

```
条件 1：身份匹配
  你正在运营或准进入这个领域（在运营/准入驻）
  ✗ 只是"想了解" → 公开信息足够，不必去

条件 2：阶段匹配
  你当前卡在"AI 用了但没形成流程"（工具级 → 流程级的瓶颈）
  ✗ 完全没用过 AI → 先去补基础，会上讲的是进阶
  ✗ 已经是链路级 → 你去是给别人做观众，不如自己复盘

条件 3：成本可接受
  通勤/差旅/时间成本你能接受
  ✗ 跨城为一场会 → 先算机会成本（这时间自己复盘更值）
```

**只满足条件 1**：信息差用公开资料补；**满足 1+2**：值得去，但要带问题清单（见下）；**满足 1+2+3**：去，并承诺 72 小时落地（否则不如不去）。

### 去之前：3 个带数字的问题模板

别空手去。用对方的痛点框架对照自己，写下 **3 个带数字的具体问题**：

```
问题 1（成本侧）：<指标> 从 <现状数字> 降到 <目标数字>，该动 <哪一层>？
  例：ACOS 从 28% 降到 20%，该动广告结构的哪一层？
问题 2（增长侧）：<方向> 的机会怎么排优先级？<我当前的约束数字> 下先做哪个？
  例：新兴站点品类机会怎么排优先级？我当前月销 3000 单下先做哪个站点？
问题 3（风险侧）：<我卡住的环节> 的失败案例里，最常见的死因是什么？
  例：旺季备货，流量与库存错配最常见的死因是哪个节点没对齐？
```

**判据**：问题必须带自己店铺的数字（28%、3000 单）——不带数字的问题是"想听个大概"，带数字的问题回来才有可执行答案。**带着问题听才有答案，带着耳朵听回来只剩 PPT。**

## 二、嵌入深度级别表（工具级 / 流程级 / 链路级）

### 级别判据

| 级别 | 判据 | 价值上限 | 典型状态 |
|---|---|---|---|
| **工具级** | 单点用 AI（用 AI 写个文案、翻译个 listing） | 省零散时间 | "AI 用了但没形成流程"——每次从零开始，效果靠手感 |
| **流程级** | 一个节点跑通（选品分析整条环节 AI 化，有 SOP） | 该节点工时减半+ | 有 SOP 文档、有输入输出格式、有人/AI 分工；但节点间还是人肉传递 |
| **链路级** | 全链路顺（上游输出=下游输入，有回流） | 成本结构变轻 | 断点检查表全过；改一个环节的数据，下游自动受益 |

### 级别自测（逐条打勾）

```
工具级 → 流程级（针对某个节点）：
  [ ] 该节点有 SOP 文档（不是靠脑子记）
  [ ] 输入输出格式固定（下游/下轮能复用）
  [ ] AI 做什么/人做什么 写明了
  [ ] 跑过 ≥2 周，有前后工时对比数字

流程级 → 链路级（跨节点）：
  [ ] 上游输出 = 下游输入（格式对齐，不是人肉转述）
  [ ] ≥1 条数据回流路径（投放→选品 或 客服→内容）
  [ ] 周期节点有倒推时间表（旺季不打架）
  [ ] 全链路有一个总提效数字（不是各节点各自为政的数字）
```

**差距的真相**：两家都用同样的 AI 工具，一家链路级一家工具级——差距不在工具订阅费（几乎为零的差距），在**可复用的效率优势**（工具级每次从零开始，链路级的效率随运行时间复利）。

## 三、头部数字降级使用法

文中 82% 爆款预测准确率、60% 运营效率提升是**头部公司（吉宏股份，上市公司）的结果**，样本单一。使用规则：

| 用途 | 允许？ | 做法 |
|---|---|---|
| 方向判断（"AI 嵌链路值得做"） | ✅ | 引用时标注"头部公司口径，样本单一" |
| 设定自己的探索方向（"先测爆款预测"） | ✅ | 当作假设，跑自己的小样验证 |
| 直接当自己的 KPI（"今年准确率也要 82%"） | ✗ | 你的数据基线、品类结构、团队能力都不同；头部是规模化后的结果，你是 0→1 |
| 对外承诺/融资材料 | ✗ 除非独立核实 | 查财报交叉验证（营收/净利可查），自述部分（准确率/效率）不可独立核实 = 标注"自述" |

**数据可信度分层**（与 ai-task-economy 同构）：
1. 财报数字（营收 24.51 亿、净利 +80.92%）：可查，中等可信
2. 公司自述（效率 +60%、准确率 82%）：不可独立核实，只做方向锚
3. 主办方效果承诺（大会能帮你怎样）：预期，不是已兑现结果，完全不作为决策依据

**一句话**：用它指方向，用它设假设，不拿它签 KPI。
