# ai-chain-embed

AI 全链路嵌入方法论技能：工具人人可得，差距在"嵌得多深"——把 AI 能力嵌入从入口到交付的整条链路，形成可复用的效率优势。四节点 AI/人配对嵌入 + 嵌入深度级别判定（工具级/流程级/链路级）+ 可量化提效目标 + 倒推时间表 + 72 小时落地。

一句话：**AI 本身不构成壁垒——把 AI 嵌入整条链路、形成可复用的效率优势，才是差距所在。谁的链路跑得顺，谁的成本结构就更轻。**

## 方法论底座

- 奥卡姆剃刀：一篇大会报名推文 = 上市公司 AI 数据钩子 + 四大痛点共鸣 + 议程卖点 + 福利临门一脚；真正主题是"AI 怎么嵌进选品—投放—履约全链路"
- 行业信号：吉宏股份 Giikin AI+（跨境社交电商营收 24.51 亿/净利 +80.92%/运营效率 +60%/爆款预测准确率 82%）——AI 已成标配，不再是加分项
- 竞争本质：工具人人可得，差距在"嵌得多深"；形成可复用的效率优势才是壁垒
- 四大痛点：政策红利看不懂 / 广告靠感觉调（ACOS 失控）/ 欧美站内卷找不到第二曲线 / 旺季流量与库存对不上
- 内容性质：营销软文，单一公司财报+主办方自述，数据需二次验证（财报可查、自述不可独立核实、效果承诺是预期）

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| "AI 用了但没形成流程" | 级别判定：工具级→流程级→链路级，自测打勾，先补流程再谈扩链路 |
| AI/人分工不清 | 四节点配对：分析（AI 跑证据/人拍板做不做）/内容（AI 初稿/人管语气合规）/投放（AI 管结构/人管预算止损线）/服务（AI 模板/人管危机） |
| 提效说不清 | 可量化目标：工时 X→Y（-Z%），拆到节点各一个数字；头部数字只做方向锚不签 KPI |
| 四个单点拼成"全链路" | 节点对齐检查：上游输出=下游输入 + ≥1 条回流路径 + 无未修复断点；断点诊断四步（格式断/传递断/消费断/回流断） |
| 旺季临场救火 | 60/30/7 倒推时间表，每节点一个检查项，检查项不过不进下一节点 |
| 参会听完没落地 | 72 小时改一条 SOP 写进流程文档，跑两周看数据；只挑一条，量化再复制 |
| 软文数字进决策 | 数据溯源：财报/自述/预期三层标注，自述与预期只做方向与假设，不签 KPI |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```
